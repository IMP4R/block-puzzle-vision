# Block Puzzle Vision Bot

macOS-распознавание block puzzle на Swift и C++ solver с Python-анализом.

## Состав

- `PUBLICATION.md`
- `blockbot`/

## Подготовка и запуск

Не импортируйте и не запускайте незнакомые модули автоматически: возможны сетевые запросы, платежные операции и другие внешние эффекты. Отсутствующие данные, сервисы и конфигурацию нужно подготовить самостоятельно.

## Ограничения снимка

- Swift распознавание экрана + C++ solver. Требует macOS и собственного разрешения Screen Recording/Accessibility. Полный цикл restart/ad/reward не реализован; исходный STATE_REVIEW включён.
- При оформлении репозитория приложение не развёртывалось, платежи и внешние API не запускались; тесты не перепроверялись.
